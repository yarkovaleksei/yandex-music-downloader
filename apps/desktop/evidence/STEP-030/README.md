Локальный Linux x64 запуск Electron 45.0.0 подтвердил Node.js 24.22.0 / Node-API 10, SQLite и системный keyring в реальном `utilityProcess`: write/read, чтение после перезапуска host, delete и отсутствие marker-секрета в временных файлах. Общий отчёт **FAIL**: графическая среда не дала `capturePage` создать backing OpenGL/EGL context (`WINDOW_CAPTURE_FAILED`; stderr сообщает `MESA-LOADER ... dri_gbm.so ... Permission denied`). Sandbox Electron не отключался. Скриншота главного окна нет; это не PASS платформенного smoke.
