# Yandex Music Downloader 0.1.0

Portable-пакеты: Linux x64 AppImage, Windows x64 ZIP, macOS arm64/x64 ZIP.

Канал обновлений настроен на GitHub Releases. Проверка и скачивание выполняются по запросу пользователя; после проверки пользователь закрывает приложение и заменяет portable-файлы вручную. Настройки и база остаются в общем каталоге состояния.

К каждому пакету приложены описание и собственная Ed25519-подпись. Это не системная подпись Apple/Microsoft; предупреждения ОС о неизвестном издателе возможны. Первая версия с настроенным каналом устанавливается вручную.
