# Yandex Music Downloader 0.1.1

Выпуск для проверки рабочего канала обновлений с версии 0.1.0. Функциональность и исходный код соответствуют 0.1.0; версия готовых пакетов увеличена до 0.1.1.

Доступны Linux x64 AppImage, Windows x64 ZIP и macOS arm64/x64 ZIP. Каждому пакету соответствуют описание и Ed25519-подпись. Проверка и скачивание выполняются по явной команде; приложение закрывают и заменяют portable-файлы вручную. Каталог состояния и аудиофайлы при замене не удаляют.

Собственная подпись описания не является системной подписью Apple/Microsoft; предупреждения ОС о неизвестном издателе допустимы.
