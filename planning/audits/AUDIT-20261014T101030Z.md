## Actual state

Владелец передал итог: 94/95 test files и 1200/1204 tests PASS. Все четыре failures относятся к M3U8. Три assertions получили абсолютные C:/Users/... строки вместо относительных; четвёртый получил VALIDATION_ERROR с cause Output root must be absolute. Новый run reported start 13:02:18, duration 62.57 s; отдельные exact timestamp/source digest/exit code не предоставлены.

На inspected source writer при optional platform undefined выбирает path.posix. Native Windows pathname не разбирается как Windows-путь, и после replaceAll разделителей становится абсолютной строкой C:/... . Чистый node:path reproducer на Linux exit 0 подтвердил различие: POSIX даёт C:/Music/Список/01 - Автор - Трек.mp3, win32 — 01 - Автор - Трек.mp3. Это моделирование path rules, не Windows runtime PASS.

Layout test для границы 255 UTF-8 байт передаёт native root и explicit linux platform. POSIX isAbsolute для C:\... false; отказ соответствует действующему layout contract. Application adapter уже передаёт host platform явно, поэтому production Windows playlist failure из этих unit failures не выводится.

## Drift / findings

- F-001 WINDOWS_M3U8_DEFAULT_PLATFORM: `m3u8.ts:13`, `:37` выбирают POSIX при отсутствии platform. Три native tests воспроизводят нарушение относительных UTF-8 строк REQ-028. Исправление должно учитывать host OS и сохранять приоритет explicit platform.
- F-002 WINDOWS_M3U8_FIXTURE_PLATFORM_MISMATCH: `m3u8.test.ts:113–136` смешивает host root с linux layout. Требуется переносимый native fixture и сохранённое независимое доказательство 255 UTF-8 байт; изменять absolute-root validation или ослаблять assertions не требуется.
- B-001 CROSS_PLATFORM_MANUAL_VERIFICATION_PENDING: Linux 9/9, Windows 0/9, macOS 0/9 на прежнем subject. Supporting tests Windows FAIL; новые 18 циклов и owner go отсутствуют. Desktop gate закрыт.
- Старый WINDOWS_TEST_FAILURE_UNCLASSIFIED уточнён этими findings. EBUSY/EPERM из общего collector не доказаны причиной текущих failures; общие retries/antivirus/admin changes не обоснованы.
