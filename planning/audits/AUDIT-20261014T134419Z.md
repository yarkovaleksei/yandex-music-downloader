## Actual state

В корне подготовлен `STEP-027-macos.zip`: 110531919 bytes, 329 entries, SHA256 `9362ba41b1db4a87654cddd1221fcc8e1ee56b9e86e84b0853038be1a44ab992`. Внутри одна папка `music-downloader-macos`, launcher, инструкция, BUNDLE.json, пустые default sources, прежние306 product source files и два оригинальных официальных Node24.21.0 tar.gz для darwin-arm64/x64.

Нужен macOS13.5 или новее. Минимальная версия подтверждена release-tag документацией и Mach-O load commands обоих Node binaries; Darwin keyring bindings требуют11.0/10.13 и не повышают этот минимум. Node archives содержат executable Node, полноценный Corepack с symlinks и лицензии. Они не перепаковывались и совпали с официальными pinned SHA256. Launcher проверяет SHA256 до распаковки, выбирает архитектуру, создаёт runtime/cache внутри комплекта и передаёт существующему runner private Node/PATH/TMP. Системная установка Node, Homebrew/Git/Python/Yarn, sudo и изменение защитных настроек не требуются.

Основной способ запуска — Terminal: набрать `bash `, перетащить `START_MACOS.command`, Enter. `chmod` не нужен. ZIP сохраняет executable bit для альтернативного двойного щелчка. Runner спрашивает собственные ссылки, выполняет текущие install/checks/build/auth/doctor и9 реальных pause/resume циклов; после завершения коллега отправляет report.json. До старта runner launcher сохраняет безопасные enum-коды в START_REPORT.json. Native Keychain/profile используются штатно.
