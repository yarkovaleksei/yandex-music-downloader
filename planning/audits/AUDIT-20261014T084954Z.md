Коллега устанавливает Node.js 24, распаковывает архив, выполняет `node docs/research/step-027-acceptance/run.mjs`, вводит свои три доступные ссылки и при необходимости проходит штатный auth в браузере. Можно заполнить только sources в config заранее. Чужие ссылки не поставляются по умолчанию; упаковщик блокирует сборку с заполненными sources. В каждой collection нужны хотя бы два доступных полных трека. Разные аккаунты могут использовать разные ресурсы; source subject должен совпадать, а фактические ссылки/variants/состав фиксируются отдельно.

Автоматически выполняются install --immutable, lint/typecheck/test/build, inventory/guard checks, отдельный signal-probe, account/doctor и девять CLI-циклов. Doctor NETWORK_ERROR повторяется максимум три раза; API/schema/auth ошибки не маскируются повтором. Каждый цикл — новый job/output, физический progress, Ctrl+C/exit 4, persisted prefix, новый resume/exit 0, validation/metadata/quality файлов, preservation completed по SHA-256/mtimeNs/inode и событиям, отсутствие part/candidate. Manifest/lease/heartbeat не редактируются.

Результат — один report.json: source/platform/build/tool identity, безопасные argv/exit/events, агрегированный progress, file inspection, retry counts, doctor и privacy flags. Raw DTO/native errors/credentials не сохраняются. На первом невыполненном условии сохраняется partial report/код; старые результаты/настройки не удаляются. --smoke и --no-prepare отмечаются явно; smoke/setup не заменяют полную матрицу. Platform PASS не означает owner go.

Windows helper запускает тестовый Node в отдельной скрытой консоли и использует AttachConsole/GenerateConsoleCtrlEvent. Перед реальной загрузкой signal-probe проверяет обработку Ctrl+C/exit 4. Подтверждение helper на настоящей Windows пока pending. Корпоративный запрет Add-Type/console API фиксируется FAIL; постоянная ExecutionPolicy не меняется. UTF-8 stdin настроен явно для путей с кириллицей.
