## Corrective actions

Для альбома выбрать минимум два доступных текущему аккаунту трека; для плейлиста также минимум два. Исполнитель и single-track album не заменяют этот сценарий. В существующем комплекте можно повторить `bash START_MACOS.command --no-prepare`: семь успешно выполненных preparation checks не повторяются, runner снова запрашивает ссылки из пустого default config и выполняет реальные циклы. При собственном заполненном config заменить album URL в нём. Сохранённые track PASS не теряются; повторные такие же циклы не увеличивают требуемые 3/3.
