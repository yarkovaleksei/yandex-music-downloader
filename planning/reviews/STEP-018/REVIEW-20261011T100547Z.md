### F-001 — Позиционный суффикс FIX превышает файловый бюджет уже проверенного core пути

**Severity:** medium
**Category:** implementation
**Location:** packages/application/src/adapters/download-files.ts:33
**Scenario:** Given Application получает допустимый available track с title из 300 ASCII символов и mp3 variant на Linux; существующий buildTrackLayout корректно сокращает basename до 255 байт. / When FIX вызывает positionedResultPath и добавляет -1 после завершения sanitizer/layout budget, затем public createDownload пишет файл через production IO. / Then Basename становится 257 байтами, загрузка возвращает job/track status failed; исходный 255-байтный core путь в том же каталоге успешно записывается.
**Expected:** Позиционное отличие должно сохранять name/path limits существующего core layout. Исправление коллизии не должно превращать поддержанный sanitizer путь в незаписываемый.
**Observed:** Public facade probe: {kind:result,status:failed,trackStatus:failed,originalCoreNameLength:255,fixedNameLength:257,originalCorePathWrite:PASS}, exit 0. Новый helper дописывает позицию к уже нормализованному basename и не возвращает путь в существующий механизм ограничения длины.
**Impact:** Допустимая metadata, которую существующий filesystem core умел сокращать, после FIX вызывает отказ загрузки. Это прямая регрессия изменённого пути, включая single-track запросы.
**Evidence kind:** reproduced
**Evidence source:** Самый дешёвый falsification experiment нового FIX helper: public IO загрузка плюс успешная запись неизменённого core layout пути на той же файловой системе.
**Verification method:** node --input-type=module public createApplication probe и fs.writeFile по исходному buildTrackLayout пути в одном временном каталоге.
**Verification result:** Public track failed; final basename 257 байт; исходный 255-байтный core basename записывается успешно.
**Fix direction:** Включить позицию в планирование имени до существующего sanitizer/truncation и учитывать его полный path budget, например через existing collection layout generators с позиционным prefix. Сохранить уникальность позиций и стабильный mapping после restart; добавить regression для basename, который исходный core уже сокращает до лимита.
