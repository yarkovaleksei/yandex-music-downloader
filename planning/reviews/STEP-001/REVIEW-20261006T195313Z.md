## Findings

### F-001 — Разбор specifier-ов расходится с ESM URL-резолюцией Node: суффиксы ?query/#fragment с '/..' и percent-encoded dot-сегменты (%2e%2e) обходят boundary rules

**Severity:** medium
**Category:** implementation
**Location:** eslint/boundaries-plugin.mjs:128
**Scenario:** Given Boundary-проход в составе yarn run lint и ESM-исходник в apps/cli, packages/core/* или packages/shared / When относительный literal specifier содержит ? или #, за которым идут сегменты /.., возвращающие путь в собственный пакет, либо percent-encoded dot-сегменты (./%2e%2e/...) / Then resolveTarget нормализует всю строку как POSIX-путь, считает импорт локальным, boundaries/* молчат; Node ESM отбрасывает query/fragment, декодирует %2e и загружает Yandex SDK, core-downloader или electron
**Expected:** Классификация specifier-а совпадает с модулем, который реально загрузит Node, либо такие формы запрещает boundaries/bypass (fail-closed, план шаг 3, docs/development.md:66).
**Observed:** lintText даёт пустые messages для 9 форм с ?/#/%2e; Node 22.13.0 и 24.21.0 загружают SDK и core-downloader по этим specifier-ам; lint, typecheck, format:check, build, test в изолированной копии проходят.
**Impact:** Теоретический обход PRN-001 и ADR-001 п.1, п.3, п.5 при зелёных проверках специально сконструированным путём; обычный код так импорты не пишет.
**Fix direction:** В resolveTarget отбрасывать ?query и #fragment и percent-декодировать путь до нормализации, либо запретить ?, # и % в относительных specifier-ах через boundaries/bypass; добавить негативные тесты и уточнить docs/development.md:66.
**Fingerprint:** sha256:3b622acc68ad3abd59461b817a06145d8f51e2a5048c16c77b7d7b592811a655

**Admissible alternatives:**
- Резолвить через new URL(specifier, base) и классифицировать декодированный pathname
- Классифицировать по фактическому разрешению Node с fail-closed

**Constraints:**
- Не ослаблять существующие правила boundaries/* и закрытые формы F-001/F-002
- Менять только eslint/** и docs/development.md

**Evidence:**
- eslint/boundaries-plugin.mjs:127-147 нормализует всю строку specifier-а через path.posix.normalize
- Пробы lintText и runtime-фикстура reviewer-а на Node 22.13.0 и 24.21.0
- eslint/boundaries.test.ts не содержит кейсов с ?, # или %
