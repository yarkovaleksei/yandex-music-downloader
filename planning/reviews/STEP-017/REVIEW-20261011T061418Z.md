**Category:** implementation

**Observed:** acquire создаёт пустые artwork и trackArtwork maps. recoverJob сохраняет статус paused, поэтому resumed attempt не проходит ветку queued/resolving и fallback trackArtwork.get(key) возвращает undefined.
**Impact:** Продолжение задания после SIGINT может создать файл без обязательной обложки либо вызвать ошибку внедрённого metadata hook, хотя исходный resolving успешно получил artwork.
**Evidence kind:** reproduced

**Verification method:** node --input-type=module с импортом packages/core/downloader/src/fixtures/manager-fixture.ts; metadata hook записывает artwork?.bytes.length; новый manager.command(resume), ожидание terminal состояния и shutdown.
**Verification result:** pausedStatus=paused; resumedStatus=completed; artworkRequests=1; processingArtworkBytes=[null].
**Fix direction:** Обеспечить восстановление готовых безопасных artwork bytes перед продолжением paused-трека в пределах разрешённого ADR-006 cache/recovery seam; передавать их processing без сетевых вызовов этой стадии.
**Fingerprint:** sha256:2fd066aa1944f593b652d3690bf0c673190b6de049e8ff21d03ec86e180290ec

**Confirmed preconditions:**

**Admissible alternatives:**
- Безопасный cache с внедрённым reader/writer и concrete test adapter, сохраняющий bytes/mimeType до variant_selected.

**Constraints:**

- Не вводить недопустимый paused→resolving transition.

**Evidence:**
