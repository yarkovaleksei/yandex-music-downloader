### F-001 — Параллельные writers используют общий временный файл

**Severity:** medium
**Category:** implementation
**Location:** packages/core/filesystem/src/m3u8.ts:37
**Scenario:** Given Два playlist jobs имеют одинаковые destination/title и независимые jobId/lease/owner lanes. / When Оба writeM3u8 доходят до rename до публикации другого вызова. / Then Один вызов получает DOWNLOAD_ERROR после удаления общего temporary path другим writer.

**Impact:** Параллельная загрузка может завершиться ошибкой после успешного скачивания треков без job.completed.

**Fix direction:** Использовать короткое уникальное имя временного файла в каталоге playlist; cleanup удаляет только файл данного вызова. Добавить regression с двумя writers и barrier перед rename.
**Fingerprint:** sha256:ab6293cecb67507f142dd6df7fb40c27cd02d040c0430f8e0771ee701f179ad7

### F-002 — Суффикс временного файла превышает допустимую длину имени

**Severity:** medium
**Category:** implementation
**Location:** packages/core/filesystem/src/m3u8.ts:37
**Scenario:** Given На Linux buildPlaylistLayout для title='Я'.repeat(130), одного трека и короткого output root возвращает допустимый basename .m3u8 в 255 bytes. / When writeM3u8 добавляет `.part` к этому итоговому basename. / Then Временное имя длиной 260 bytes отвергается с ENAMETOOLONG, преобразованным в DOWNLOAD_ERROR.
**Expected:** Writer публикует файл по допустимому пути buildPlaylistLayout.
**Observed:** Суффикс `.part` увеличивает basename до 260 bytes; реальный open отвергается с ENAMETOOLONG.
**Impact:** Для допустимого длинного названия playlist .m3u8 не создаётся и завершающая операция job возвращает ошибку.
**Evidence kind:** reproduced
**Evidence source:** Собственный inline runtime experiment independent reviewer с текущим built export filesystem.
**Verification method:** node --input-type=module: buildPlaylistLayout и writeM3u8 с default FsOps в mkdtemp; каталог удалён после проверки.
**Verification result:** Exit 0; finalBytes=255, temporaryBytes=260; rejected DOWNLOAD_ERROR, causeCode=ENAMETOOLONG.
**Fix direction:** Использовать короткий уникальный temporary basename в том же каталоге, независимо от итогового basename. Добавить regression предельного UTF-8 имени из buildPlaylistLayout.
**Fingerprint:** sha256:0ee6f1d11838bdf2b75ee5f24ca8febb8db979898fd9526a219f2e8e88a98832

**Confirmed preconditions:**
- Linux filesystem с NAME_MAX=255 bytes.
- buildPlaylistLayout получает title='Я'.repeat(130), один трек и короткий абсолютный output root.

**Constraints:**
- Сохранить существующие sanitizer/layout алгоритмы и filesystem ограничения; тот же repair закрывает оба findings.

**Evidence:**
- packages/core/filesystem/src/m3u8.ts:37
- packages/core/filesystem/src/layout.ts:144
- packages/core/filesystem/src/layout.ts:251
- packages/application/src/adapters/download-files.ts:87
