### F-001 — Writer скрывает filesystem-ошибку за METADATA_ERROR и отменяет глобальную паузу job

**Severity:** medium
**Category:** implementation
**Location:** packages/metadata/src/index.ts:80
**Scenario:** Given Default application writer повторно загружает album с overwrite=true и concurrency=1; .part и каталог доступны, existing cover.jpg имеет mode0444. / When Writer завершает tagging и пытается записать cover.jpg. / Then EACCES становится METADATA_ERROR; job failed/control running, оба track failed вместо pause после первого отказа.
**Expected:** Сохраняется безопасный PERMISSION_DENIED, core classifier возвращает pause_job и следующий трек queued.
**Observed:** Общий catch оборачивает EACCES в MetadataError; classifier DomainError METADATA_ERROR даёт fail/track и не читает cause.
**Impact:** Неверная диагностика/восстановление, resume не продолжает failed-треки; очередь продолжает безуспешную загрузку.
**Evidence kind:** reproduced
**Evidence source:** Own independent Node runtime probes current writer и default createApplication на физических offline bytes.
**Verification method:** Real filesystem refusal, repeat public createApplication/createDownload, persisted manifest.
**Verification result:** Потеря PERMISSION_DENIED и продолжение очереди воспроизведены.
**Fix direction:** Сохранить безопасную filesystem-классификацию через shared normalizeDomainError вокруг readFile/writeFile; METADATA_ERROR только для tagging. Узкий regression штатного writer с недоступным sidecar подтверждает paused/PERMISSION_DENIED и queued следующего трека без filesystem details.
**Fingerprint:** sha256:ddb1177ecfc348bf4418abb332be2b7b996fef812ae326b603030ec01005dc0f

**Confirmed preconditions:**
- Каталог/.part доступны, только sidecar read-only.
- Default composition без override.
- Classifier различает EACCES и METADATA_ERROR.

**Admissible alternatives:**
- Нормализовать filesystem ошибки отдельных read/write, сохранив общий MetadataError для TagLib.

**Constraints:**
- Не добавлять metadata→core dependency.
- Не менять state machine/shared DTO/manifest.
- Не публиковать исходные message/cause/stack.

**Evidence:**
- packages/metadata/src/index.ts:67-80 — catch маскирует filesystem writeFile errors.
- packages/core/retry/src/classify.ts:47-64,74-76 — PERMISSION_DENIED/EACCES pause_job; METADATA_ERROR fail/track.
- packages/application/src/composition-root.ts:98-126; packages/core/downloader/src/pipeline.ts:218-230 — reachable default writer.
- Independent Node probe exit0: cover.jpg0444 → METADATA_ERROR cause.code=EACCES, classify wrapper fail/track, cause pause_job/PERMISSION_DENIED.
- Independent full application probe exit0: успешный album2 → chmod cover0444 → overwrite concurrency1; persisted job failed/control running/оба tracks failed METADATA_ERROR. Temp removed.
