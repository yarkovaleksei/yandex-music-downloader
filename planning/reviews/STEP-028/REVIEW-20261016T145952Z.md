### F-001 — Renderer может передать произвольный абсолютный путь каталога (UNC/WebDAV/device), который main проверяет через fs

**Severity:** medium
**Category:** implementation
**Location:** docs/adr/ADR-016-desktop-ipc-contract.md:63
**Scenario:** Given Скомпрометированный renderer на Windows / When вызывает создание загрузки или сохранение настроек с путём \\attacker\share / Then fs-проверка в main открывает SMB/WebDAV-сессию с NTLM-аутентификацией, host пишет контент на чужой share, ответ раскрывает существование каталогов
**Expected:** Недоверенный renderer не может инициировать доступ к произвольным путям, в том числе сетевым (ADR-015/016 Security implications)
**Observed:** ADR-016 допускает «абсолютный путь существующего каталога» с проверкой схемой и fs; path.win32.isAbsolute принимает UNC и device-пути; DownloadRequest.destination доходит до записи (domain.ts:107, jobs.ts:99, layout.ts:108)
**Impact:** Утечка NetNTLMv2/relay, запись на чужой share, oracle существования каталогов — противоречие заявленной изоляции renderer
**Evidence kind:** inferred
**Evidence source:** security reviewer: trust boundary renderer → main в ADR-016
**Verification method:** Сверка контракта ADR и кода плюс reproducer path.win32.isAbsolute на Node
**Verification result:** Все предпосылки подтверждены; утечка NTLM выведена из документации Microsoft, на Windows не запускалось
**Fix direction:** Каталог назначения и output directory выбираются только main-only диалогом; main хранит выбранные каталоги (allowlist/непрозрачный id), renderer передаёт ссылку, а не путь
**Fingerprint:** sha256:0526ddefa306d11a417ac1d45f8c5a05406ab7c3ee89a6712ebbe1c6147f03e2

**Confirmed preconditions:**
- Renderer недоверенный (ADR-015/016)
- ADR-016 разрешает путь из renderer с fs-проверкой
- path.win32.isAbsolute принимает UNC
- Windows x64 — целевая платформа (REQ-045)

**Admissible alternatives:**
- Синтаксическая проверка в main до любого fs/shell-вызова: на win32 только пути локального диска X:\, отказ для \\, //, \\?\, \\.\; тесты с UNC и device-путями

**Constraints:**
- Только docs/adr/ADR-015, ADR-016

**Evidence:**
- ADR-016:63
- packages/shared/src/domain.ts:107
- packages/application/src/jobs.ts:99
- packages/core/filesystem/src/layout.ts:108
- Node path.win32.isAbsolute('\\\\attacker\\share') === true
- Microsoft Learn: Restrict NTLM outgoing по умолчанию Allow all
