### F-001 — Обработчик паузы поглощает Ctrl+C во время auth

**Severity:** medium
**Category:** implementation
**Location:** apps/cli/src/runner.ts:159
**Scenario:** Given Команда auth ожидает завершения Device Authorization. / When Пользователь нажимает Ctrl+C. / Then Обработчик SIGINT сохраняет requested=true, но не прекращает процесс и не отменяет авторизацию.
**Expected:** Для auth должна сохраняться возможность прекращения процесса CLI, предусмотренная ADR-010; обработчик паузы job применяется к потоковым командам.
**Observed:** Обработчик устанавливается для всех команд. В auth beforeInvocation не вызывается, invoked=false и сигнал поглощается. Child после настоящего SIGINT продолжил authenticate и завершился exit 0.
**Impact:** Ctrl+C не прерывает авторизацию; credentials могут сохраниться после попытки пользователя остановить процесс.
**Evidence kind:** reproduced
**Evidence source:** Independent lead process experiment собранного runner и targeted production auth inspection.
**Verification method:** SIGINT дочернему процессу после начала authenticate и проверка конечного результата; исключён независимый handler.
**Verification result:** Процесс продолжил auth и завершился exit0.
**Fix direction:** Ограничить обработчик паузы потоковыми командами, сохранив обычное прекращение auth по SIGINT; добавить process проверку ожидающего authenticate.
**Fingerprint:** sha256:4f103bab6d9738ffab4045b82c2d9d5c9a19a4bd20ee393959def563d71ee31d

**Confirmed preconditions:**
- authenticate ожидает подтверждения.
- Runner перехватывает process SIGINT при invoked=false.
- Provider/browser не имеют отдельного SIGINT handler.

**Constraints:**
- Только apps/cli.
- Не вводить новый auth signal/DTO и не менять provider flow.
- Сохранить H-002 lifecycle паузы загрузки.

**Evidence:**
- runner.ts:159-165 безусловно устанавливает installPauseOnSigint; commands.ts:26 вызывает authenticate до beforeInvocation; signals.ts:99-105 действует только при wasInvoked.
- Reviewer process experiment: runner argv auth --json, signals=process, authenticate ждёт 800 ms; после AUTH_WAIT настоящий SIGINT, итог exit0 и kind=result authenticate.
- Application facade прямо ждёт provider.authenticate; targeted auth/browser inspection не нашла другого SIGINT handler. ADR-010 разрешает отмену прекращением процесса CLI.

### F-002 — Help нарушает NDJSON contract при --json

**Severity:** low
**Category:** implementation
**Location:** apps/cli/src/runner.ts:103
**Scenario:** Given CLI запущен с --help --json. / When Runner обрабатывает help. / Then Справка записывается в stdout вместо CliRecord.
**Expected:** Каждая строка stdout в --json соответствует CliRecord; human output не смешивается с этим каналом.
**Observed:** node apps/cli/dist/index.js --help --json: exit0, пять непустых строк stdout, ни одна не JSON, stderr пуст.
**Impact:** Разрешённая комбинация ломает потребителя NDJSON.
**Evidence kind:** reproduced
**Evidence source:** Собранный CLI и прямой CliRecord contract STEP-019/REQ-031/ADR-007.
**Verification method:** Запуск CLI и JSON.parse каждой непустой строки stdout.
**Verification result:** Все пять строк не проходят JSON.parse.
**Fix direction:** В JSON-режиме направить human help в stderr либо отвергнуть комбинацию безопасным CommandResult; покрыть process smoke.
**Fingerprint:** sha256:4c8cecfdbfb5d194654f03e0ac94d553f4db168c57099a6ab0d6eaef4d70349c

**Confirmed preconditions:**
- Парсер принимает --help --json.

**Admissible alternatives:**
- Пустой stdout и справка в stderr.
- Usage error через существующий CommandResult.

**Constraints:**
- Не создавать JSON DTO справки.
- Обрабатывать help до application.
- Только apps/cli.

**Evidence:**
- runner.ts:103-105 безусловно host.stdout(helpText).
- Independent process command node apps/cli/dist/index.js --help --json: exit0, stdoutNonemptyLines5,validJsonLines0,stderrBytes0.
- STEP-019 AC2, REQ-031 и ADR-007 запрещают human stdout в JSON-режиме без исключения help.
