### F-001 — Ошибка отмены upstream прерывает нормализацию разрыва audio stream

**Severity:** medium
**Category:** implementation
**Location:** packages/providers/yandex-music/src/audio/stream.ts:133
**Scenario:** Given Авторизованный provider подтвердил available=true и preview=false, открыл полный MP3 и передал caller первые 4 bytes. CDN body является native fetch ReadableStream. / When Соединение обрывается во время следующего чтения: upstream становится errored, reader.read() и последующий reader.cancel() отклоняются исходным TypeError. / Then await reader.cancel() внутри catch отклоняется раньше release() и controller.error(normalizedError). Публичный reader получает исходный TypeError с cause UND_ERR_SOCKET вместо retryable NETWORK_ERROR; underlying reader остаётся locked.
**Expected:** ADR-009 требует NETWORK_ERROR для разрыва соединения и запрещает перенос library message/cause в публичную ошибку. Implementation plan STEP-010 unit 4 требует освобождения reader при error, unit 5 — безопасной диагностики без исходного message/cause.
**Observed:** Публичный provider с настоящим native fetch body после socket.destroy() вернул TypeError, code=null, cause.code=UND_ERR_SOCKET. Отдельная проверка той же ветки сохранила точный исходный TypeError, synthetic signed URL в message/cause и body.locked=true. Во всех случаях это происходит после уже прочитанного корректного MP3 prefix.
**Impact:** Caller теряет обязательную классификацию retryable transport failure и получает необработанное исключение с исходной диагностикой. Error boundary допускает raw message/cause и не освобождает upstream reader в обычном сценарии разрыва соединения.
**Evidence kind:** reproduced
**Evidence source:** .harness/local/step010-lead-midstream-repro.mjs
**Verification method:** Минимальная проверка действующего dist createAudioStream и public facade с validated synthetic API/XML и native fetch body локального HTTP server; принудительный socket.destroy() после прочитанного prefix. Это read-only проверка, production files не изменялись.
**Verification result:** Оба сценария подтвердили bypass нормализации; public native body вернул TypeError/code=null/cause UND_ERR_SOCKET, synthetic error сохранил исходный message/cause и locked reader. Команда exit 0.
**Fix direction:** Не позволяйте отклонению cleanup отменять исходную классификацию: обработайте отказ reader.cancel(), гарантируйте release() и завершите output stream безопасным ProviderError NETWORK_ERROR без raw cause либо AbortError при отмене caller. Добавьте один focused regression для partial prefix -> upstream error, проверяющий код/безопасную ошибку и освобождение reader.
**Fingerprint:** sha256:07ef776746160e7707ecd53c6828c3d1853416d353ed7a800a554577697b0278

**Confirmed preconditions:**
- Публичный AuthFetch DI и default globalFetch возвращают ReadableStream body; openAudioStream передаёт его в checkedStream.
- Перед ошибкой прочитан valid MP3 prefix, поэтому подтверждён именно midstream path.
- Native body при socket interruption переходит в errored state; повторный cancel отклоняется тем же исходным исключением.

**Admissible alternatives:**
- Общий private cleanup helper с перехватом cancel rejection и finally release(), используемый этой error веткой.

**Constraints:**
- Исправление только внутри текущего provider STEP-010, без новой retry policy и изменения shared MusicProvider.
- Сохранить byte-exact prefix, существующие Range/fallback и AbortError semantics.
- Не сохранять реальную signed URL, credentials или audio bytes; regression использует synthetic данные.

**Evidence:**
- packages/providers/yandex-music/src/audio/stream.ts:132-141 — await reader.cancel() предшествует release() и нормализации ошибки и не перехватывает собственный rejection.
- packages/providers/yandex-music/src/yandex-music-auth.ts:267-289 и :518 — public openAudioStream передаёт native fetch response.body в createAudioStream; этот путь является production entry point.
- node .harness/local/step010-lead-midstream-repro.mjs; exit 0 означает подтверждение дефекта. public-native-body: publicFacade=true, nativeFetchBody=true, prefixBytes=4, errorName=TypeError, errorCode=null, causeCode=UND_ERR_SOCKET.
- Та же команда, synthetic-error-boundary: prefixBytes=4, sameRawError=true, secretInPublicMessage=true, secretInPublicCause=true, upstreamLocked=true. Значения synthetic secrets в stdout не печатаются.
- docs/adr/ADR-009-yandex-adapter-strategy.md:38,60,68,96; planning/tasks/STEP-010.md:177,193-195 — обязательные безопасная нормализация и cleanup.
- node packages/testing/scripts/run-yarn.mjs test packages/providers/yandex-music/src/audio/audio.test.ts; exit 0, 22 tests PASS. Существующий suite не проверяет errored body после partial bytes.
