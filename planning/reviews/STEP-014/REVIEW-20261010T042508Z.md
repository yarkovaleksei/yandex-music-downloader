### F-001 — В модели control job нет команды retry: отказ retry для cancelled job из плана не реализован и не покрыт тестом

**Severity:** medium
**Category:** implementation
**Location:** packages/core/downloader/src/state/control.ts:16
**Scenario:** Given Job в control=cancelled содержит трек в статусе failed / When Вызывающий слой обрабатывает команду retry для job через API state machine / Then Ни одна функция не отвергает retry для cancelled job: JobControlCommand = pause|resume|cancel, а transitionTrack(failed, retry) возвращает ok без учёта control
**Expected:** По плану STEP-014 (шаг 2) и ADR-003 («resume и retry для cancelled job — ошибка») в control job есть операция retry; при control=cancelled она отвергается, это закреплено тестом.
**Observed:** Отказ реализован только для pause, resume, cancel; retry на уровне job нет в типе и в экспорте. Тест keeps cancelled terminal проверяет только pause/resume/cancel и resumeJob. Приведённая через as never команда retry для paused job уходит в ветку resume.
**Impact:** У правила нет владельца в state machine: STEP-017/CLI продублирует проверку или пропустит её, и retry у cancelled job молча вернёт failed-треки в queued.
**Evidence kind:** contract
**Evidence source:** STEP-014 Implementation plan шаг 2 и ADR-003 Control job
**Verification method:** Чтение control.ts, control.test.ts, index.ts и vitest-эксперимент над экспортом в scratchpad
**Verification result:** Операции retry на уровне job нет; приведённая retry для paused job уходит в resume
**Fix direction:** Добавить в control job явную операцию retry: при control=cancelled отвергается, при running или paused успешна без изменения control и не проходит через ветку resume; экспортировать и покрыть тестом.
**Fingerprint:** sha256:6d9b157e71aacc7debf08d6667be78597be8fea490718e1677f0dfb902d9f9b0

**Confirmed preconditions:**
- План ready, retry для cancelled job заявлен
- В core-downloader нет другой функции retry на уровне job

**Admissible alternatives:**
- Добавить 'retry' в JobControlCommand с отдельной веткой в transitionJobControl
- Отдельная чистая функция retryJob(state)

**Constraints:**
- Править только packages/core/downloader/src/state/** и реэкспорт в src/index.ts
- Не менять семантику pause/resume/cancel, pauseJobOnFatalError и AUTH_REQUIRED-resume

**Evidence:**
- planning/tasks/STEP-014.md: Implementation plan, шаг 2 — resume и retry для cancelled job отвергаются
- docs/adr/ADR-003-download-state-machine.md — resume и retry для cancelled job — ошибка
- packages/core/downloader/src/state/control.ts:16 — JobControlCommand без retry
- packages/core/downloader/src/state/control.test.ts — для cancelled нет проверки retry
