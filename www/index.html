Без регистрации на сторонних сайтах: вход через браузер на стороне Яндекса.

  1. Скачайте приложение Один файл для вашей системы — устанавливать ничего не нужно.
  2. Войдите в аккаунт Подтвердите вход в браузере. Пароль вводится у Яндекса, приложение его не видит.
  3. Вставьте ссылку Выберите качество и папку — готовые файлы появятся с тегами и обложками.
