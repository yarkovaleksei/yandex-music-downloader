# Правила работы с проектом

Yandex Music Downloader — TypeScript monorepo: CLI и Electron-приложение
на React/MUI, общий application API, SQLite и отдельный provider Яндекс Музыки.

- Пиши ответы, документацию, комментарии и сообщения коммитов по-русски.
- Не создавай коммиты и не отправляй изменения без явного поручения.
- Сохраняй существующие незакоммиченные изменения.
- CLI и UI не обращаются к Yandex API напрямую. Специфичный код и SDK
  находятся только в packages/providers/yandex-music.
- Не сохраняй и не логируй токены, cookies, credentials и подписанные URL
  в открытом виде. Не публикуй персональные абсолютные пути.
- Загружай только контент, доступный текущему аккаунту, без обхода ограничений.
- Выбирай минимально достаточные изменения; не добавляй работу заодно.
- Комментарии должны кратко объяснять нетривиальное поведение.
- Запускай проверки соразмерно изменениям; прямой запрет пользователя
  на тесты, сборки и другие проверки имеет приоритет.
- Основные документы: README.md, docs/development.md, docs/architecture.md.
- Не переусложняй. Если исходное требование пользователя уже выполнено и основные проверки проходят, не продолжай хардненинг, не добавляй новые тесты, проверки и циклы FIX → REVIEW по редким или экзотическим сценариям.
- Если дальнейшая работа выходит за рамки исходной просьбы, не делай её молча. Задай один короткий вопрос с явным подтверждением, например: «Продолжать укреплять X? Это займёт Y».
- Предупреждай о масштабе заранее, а не после того, как потрачено время и токены.
- Варианты для пользователя формулируй простым языком, без внутреннего жаргона.
