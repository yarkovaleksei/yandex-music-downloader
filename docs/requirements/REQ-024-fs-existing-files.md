# REQ-024 — [FILESYSTEM] Поведение при существующих файлах

## Requirement

Если файл с итоговым путём уже существует и проходит валидацию, по умолчанию он пропускается (skip-existing); существующий файл, не прошедший валидацию, считается отсутствующим и заменяется только после успешной загрузки через `.part`; `--overwrite` заменяет его через `.part` и атомарный rename; одновременное указание `--overwrite` и `--skip-existing` — ошибка использования CLI.

## Rationale

Предсказуемое поведение повторного запуска без потери файлов пользователя; default skip-existing подтверждён владельцем продукта.

## Acceptance

- Повторный запуск `download` по уже скачанному альбому не загружает аудио повторно: треки получают состояние `skipped`, их пути записываются в manifest и попадают в `.m3u8` плейлиста.
- `--overwrite` заменяет файл только после успешной загрузки новой версии.
- Одновременные `--overwrite --skip-existing` завершаются кодом ошибки использования без начала загрузки.
