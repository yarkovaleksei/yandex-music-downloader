# REQ-054 — [PACKAGING] Дистрибутивы для всех целевых ОС

## Requirement

Создаются portable-дистрибутивы без установщика: Windows x64 ZIP с готовым приложением, macOS .app ZIP для arm64 и x64, Linux x64 AppImage. Всё собирается только на Linux. По решению владельца от 2026-10-29 платные сертификаты, системная подпись и notarization не требуются. Portable означает запуск без установки, а не перенос секретов/базы рядом с исполняемым файлом: общий каталог состояния сохраняется по ADR-014.

Решением владельца от 2026-10-29 все новые нативные проверки Windows/macOS выполняются единым финальным STEP-054 после разработки, упаковки и механизмов проверенных обновлений. Отсутствие этих прогонов не блокирует промежуточные STEP; там обязательны Linux-проверки. Перед выпуском финальная Windows/macOS приёмка обязательна. Все сборки выполняются только на Linux; на целевых ОС проверяются готовые артефакты. При добавлении новой работы финальный STEP-054 должен зависеть от её завершения.

## Rationale

Brief §49 STEP 6, §55.

## Acceptance

- Локальная сборка на Linux создаёт готовые артефакты для Windows x64, macOS arm64/x64 и Linux x64.
- Готовое приложение запускается без установщика на чистой ОС: Linux проверяется в STEP-035/036, Windows/macOS — в финальном STEP-054 (Evidence). Предупреждения ОС о неизвестном издателе допустимы.
- Версия релизного артефакта соответствует тегу релиза; проверочные локальные версии явно помечены и не публикуются как релиз.
