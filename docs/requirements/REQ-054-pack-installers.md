# REQ-054 — [PACKAGING] Дистрибутивы для всех целевых ОС

## Requirement

Создаются portable-дистрибутивы без установщика: Windows x64 portable exe, macOS .app ZIP для arm64 и x64, Linux x64 AppImage. Всё собирается только на Linux. По решению владельца от 2026-10-29 платные сертификаты, системная подпись и notarization не требуются. Portable означает запуск без установки, а не перенос секретов/базы рядом с исполняемым файлом: общий каталог состояния сохраняется по ADR-014.

По решению владельца от 2026-10-29 нативные проверки Windows/macOS выполняются на готовых артефактах после разработки и упаковки; промежуточные изменения проверяются на Linux. Перед выпуском обязательна финальная приёмка Windows/macOS. Все сборки выполняются только на Linux; на целевых ОС проверяются готовые артефакты без компиляции.

Отчёты нативной приёмки относятся к конкретным revision/build ID и хешам. Для ранее согласованных переносимых изменений UI без новых платформенных интеграций разрешена отдельная Linux-проверка; прежний платформенный PASS не переносится автоматически на новую сборку.

## Rationale

Готовые дистрибутивы позволяют запускать приложение на поддерживаемых ОС без ручной сборки исходников.

## Acceptance

- Локальная сборка на Linux создаёт готовые артефакты для Windows x64, macOS arm64/x64 и Linux x64.
- Готовое приложение запускается без установщика на чистой ОС: результаты для Linux, Windows и macOS привязаны к проверенным артефактам. Предупреждения ОС о неизвестном издателе допустимы.
- Версия релизного артефакта соответствует тегу релиза; проверочные локальные версии явно помечены и не публикуются как релиз.
