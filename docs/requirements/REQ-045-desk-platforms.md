# REQ-045 — [DESKTOP] Целевые платформы и независимость core

## Requirement

Electron-приложение собирается только на Linux для Windows x64, macOS arm64, macOS x64 и Linux x64 и запускается на каждой целевой ОС; downloader core не зависит от Electron или React и допускает добавление новых архитектур без переработки.

Решением владельца от 2026-10-29 все новые нативные проверки Windows/macOS выполняются единым финальным STEP-054 после разработки, упаковки и механизмов подписания/обновления. Отсутствие этих прогонов не блокирует промежуточные STEP; там обязательны Linux-проверки. Перед выпуском финальная Windows/macOS приёмка обязательна. Все сборки выполняются только на Linux; на целевых ОС проверяются готовые артефакты. При добавлении новой работы финальный STEP-054 должен зависеть от её завершения.

## Rationale

Кроссплатформенность — часть определения готовности (brief §4.3, §55).

## Acceptance

- Сборка артефактов для всех четырёх целей успешно выполняется на Linux; Evidence фиксирует build ID, хеш готовых файлов, целевые ОС/архитектуру и revision. На Windows/macOS приложение не собирается: проверяются запуск и работа полученного готового артефакта.
- Пакеты `packages/core/**` собираются и тестируются без зависимостей Electron/React.
- Smoke-запуск собранного приложения открывает главное окно: Linux проверяется в промежуточных STEP; Windows/macOS — только в финальном STEP-054 с Evidence.
