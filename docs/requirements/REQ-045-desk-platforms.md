# REQ-045 — [DESKTOP] Целевые платформы и независимость core

## Requirement

Electron-приложение собирается только на Linux для Windows x64, macOS arm64, macOS x64 и Linux x64 и запускается на каждой целевой ОС; downloader core не зависит от Electron или React и допускает добавление новых архитектур без переработки.

По решению владельца от 2026-10-29 нативные проверки Windows/macOS выполняются после разработки и упаковки на готовых артефактах, собранных только на Linux. Перед выпуском финальная приёмка Windows/macOS обязательна; промежуточные изменения проверяются на Linux.

Для ранее согласованных переносимых изменений UI без новых платформенных интеграций разрешена отдельная Linux-проверка. Нативные отчёты относятся только к проверенным revision/build ID и не подтверждают будущие UI-сборки.

## Rationale

Кроссплатформенность — часть определения готовности.

## Acceptance

- Сборка артефактов для всех четырёх целей успешно выполняется на Linux; Evidence фиксирует build ID, хеш готовых файлов, целевые ОС/архитектуру и revision. На Windows/macOS приложение не собирается: проверяются запуск и работа полученного готового артефакта.
- Пакеты `packages/core/**` собираются и тестируются без зависимостей Electron/React.
- Smoke-запуск собранного приложения открывает главное окно: Linux проверяется в ходе разработки, Windows/macOS — при финальной платформенной приёмке готовых артефактов.
