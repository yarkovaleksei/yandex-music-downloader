# REQ-015 — [DOWNLOAD] Обработка устаревших signed URL

## Requirement

Если ссылка на аудио, выданная provider, истекла или стала недействительной во время загрузки, core запрашивает новый поток у provider (в пределах лимита попыток) и не завершает трек generic-ошибкой. TTL и правила обновления определяются по evidence (OQ-008).

## Rationale

Подписанные ссылки CDN имеют ограниченное время жизни, а большие плейлисты загружаются долго.

## Acceptance

- Интеграционный тест с mock provider, который отдаёт истёкшую ссылку для первой попытки, завершается успешной загрузкой после повторного `openAudioStream`.
- Повторный запрос ссылки учитывается в лимите `maxAttempts` и не создаёт бесконечный цикл.
- Signed URL не сохраняется в manifest и не попадает в логи.
- Ответ с недействительной подписью классифицируется как `STREAM_EXPIRED`, а не как `AuthenticationError`.
