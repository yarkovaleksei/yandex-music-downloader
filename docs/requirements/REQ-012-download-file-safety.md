# REQ-012 — [DOWNLOAD] Запись через .part и атомарная финализация

## Requirement

Файл никогда не пишется сразу под конечным именем: поток записывается в `*.part`, затем выполняются close, flush, проверка, запись метаданных и обложки, финальная проверка и атомарный rename в конечное имя. Приложение не оставляет под конечным именем повреждённые или неполные файлы.

## Rationale

Прерывание или ошибка не должны порождать «успешные», но битые файлы (brief §17, §55).

## Acceptance

- Интеграционный тест с обрывом потока на середине оставляет только `.part` (или ничего) и не создаёт файл с конечным именем.
- Ошибка при записи метаданных/валидации не приводит к появлению конечного файла.
- Rename выполняется только после успешной валидации; при `--overwrite` прежний файл остаётся нетронутым до успешного rename.
