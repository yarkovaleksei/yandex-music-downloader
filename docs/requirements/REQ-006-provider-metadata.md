# REQ-006 — [PROVIDER] Получение метаданных track, album, playlist

## Requirement

Provider возвращает доменные `Track`, `Album`, `Playlist` с идентификатором, названием, исполнителями, альбомом, длительностью, номером трека и диска, годом, жанром (если сообщён) и непрозрачную ссылку на обложку (`ArtworkRef`); для playlist — владельца и упорядоченный список треков с позициями.

## Rationale

Метаданные нужны для планирования, тегов и структуры каталогов (brief §8, §46).

## Acceptance

- Для каждого из типов track/album/playlist существует unit-тест маппинга сохранённой fixture-ответа в доменный тип, включая отсутствующие необязательные поля.
- Playlist с N треками возвращается с N элементами и позициями 1..N в порядке источника.
- Недоступный трек в составе album/playlist помечается в результате признаком недоступности и не прерывает получение остальных треков.
