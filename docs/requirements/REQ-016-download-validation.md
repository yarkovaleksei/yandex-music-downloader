# REQ-016 — [DOWNLOAD] Валидация скачанного файла

## Requirement

После загрузки выполняются проверки: файл существует, размер больше нуля, поток завершён ожидаемо, контейнер распознаётся; при наличии ожидаемой длительности — длительность файла соответствует ей в допустимом допуске. FFmpeg — опциональная зависимость: загрузка и базовая валидация работают без него.

## Rationale

Битые файлы должны быть обнаружены до финального имени.

## Acceptance

- Unit-тесты подтверждают отказ для пустого файла, обрезанного потока, нераспознаваемого контейнера и значительного расхождения длительности.
- Допуск по длительности зафиксирован в коде/документации (см. docs/architecture.md, раздел Validation) и покрыт тестами на границах.
- При отсутствии FFmpeg в PATH загрузка трека завершается успешно, а `doctor` сообщает «optional / not installed».
