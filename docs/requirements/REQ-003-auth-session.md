# REQ-003 — [AUTH] Определение аккаунта и истёкший токен

## Requirement

Команда `account` показывает текущий аккаунт либо явное состояние «не авторизован». При истёкшем или отозванном токене система завершает операцию доменной `AuthenticationError` с инструкцией повторной авторизации, без необработанного исключения и без автоматических retry. Job при этом прекращает планирование новых треков и переводится в `control = paused` с причиной `AUTH_REQUIRED`; после `auth` команда `resume` продолжает загрузку оставшихся треков.

## Rationale

Пользователь должен отличать проблему авторизации от сетевой или API-проблемы.

## Acceptance

- `account` без токена возвращает состояние «не авторизован» с ненулевым exit code и без stack trace.
- При ответе провайдера 401/эквиваленте, который не удаётся обработать обновлением токена (если refresh поддерживается по OQ-001), затронутый трек сохраняется в manifest как `failed` с кодом `AUTH_ERROR`, job — как `paused` с причиной `AUTH_REQUIRED`; автоматического повтора нет.
- После успешного `auth` команда `resume` переводит только затронутый `AUTH_ERROR`-трек в очередь и продолжает незавершённую часть job по ADR-006.
- Сообщение об ошибке содержит инструкцию выполнить `music-downloader auth`.
