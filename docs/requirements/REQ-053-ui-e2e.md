# REQ-053 — [UI] End-to-end сценарий desktop

## Requirement

Автоматический E2E-тест проходит сценарий: resolve URL → start download → pause → resume → complete → открыть историю.

По решению владельца от 2026-10-29 нативные проверки Windows/macOS выполняются на готовых артефактах после разработки и упаковки; промежуточные изменения проверяются на Linux. Перед выпуском обязательна финальная приёмка Windows/macOS. Все сборки выполняются только на Linux; на целевых ОС проверяются готовые артефакты без компиляции.

Отчёты нативной приёмки относятся к конкретным revision/build ID и хешам. Для ранее согласованных переносимых изменений UI без новых платформенных интеграций разрешена отдельная Linux-проверка; прежний платформенный PASS не переносится автоматически на новую сборку.

## Rationale

E2E-сценарий проверяет совместную работу интерфейса, IPC, application API и сохранения результатов загрузки.

## Acceptance

- E2E-сценарий запускается локально на mock provider и завершается успешно.
- Сценарий проверяет появление файла в выходном каталоге и записи в истории.
- Сценарий выполняется локально на Linux; Windows/macOS проверяются при платформенной приёмке готовых артефактов, собранных только на Linux. Прежние отчёты сохраняются как доказательство проверенной версии. Нативный запуск не компилирует TypeScript, renderer или E2E host; инструменты сборки на Windows/macOS не требуются.
