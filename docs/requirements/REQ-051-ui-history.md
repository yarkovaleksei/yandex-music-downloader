# REQ-051 — [UI] Экран истории

## Requirement

Экран History показывает завершённые задания (поиск, фильтры, тип, число треков, размер, дата) с действиями Download again, Remove from history, Open folder; удаление записи из истории не удаляет аудиофайлы.

## Rationale

Brief §33, §36.

## Acceptance

- Удаление записи из истории не изменяет файловую систему (тест с fixture-каталогом).
- Поиск и фильтр по типу изменяют отображаемый список в тесте компонента.
- Download again создаёт новое задание с тем же источником и настройками.
