# REQ-051 — [UI] Экран истории

## Requirement

Экран History показывает завершённые задания (поиск, фильтры, тип, число треков, размер, дата) с действиями Download again, Remove from history, Open folder; удаление записи из истории не удаляет аудиофайлы.

Новые задания сохраняют полный снимок эффективных настроек для повторной загрузки. Старые записи без полного снимка остаются видны, но повторная загрузка недоступна с объяснением причины: неизвестные исходные настройки нельзя подменять текущими значениями по умолчанию.

## Rationale

Brief §33, §36.

## Acceptance

- Удаление записи из истории не изменяет файловую систему (тест с fixture-каталогом).
- Поиск и фильтр по типу изменяют отображаемый список в тесте компонента.
- Download again для записи с полным снимком создаёт новое задание с тем же источником и настройками.
- Для старой записи без полного снимка повторная загрузка явно недоступна; новое задание не создаётся (тест совместимости).

- Недоступная локальная папка задания имеет отключённое действие с объяснением; проверка не задерживает показ истории и её фильтры. При исчезновении после проверки отказ понятен и виден в текущей области окна. Открытие папки не перечитывает историю и обложки.
