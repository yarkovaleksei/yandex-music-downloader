# REQ-055 — [PACKAGING] Архитектура автообновления и подписания

## Requirement

Определены и реализованы архитектура автообновления и подписания (code signing / notarization) дистрибутивов; ключи и сертификаты не хранятся в репозитории.

## Rationale

Brief §49 STEP 6. Реальная подпись требует сертификатов и аккаунтов владельца (Apple Developer ID, Windows code signing) — OQ-013.

## Acceptance

- Документированная схема обновления проверена обновлением с версии N на N+1.
- Подписанные артефакты проходят проверку подписи/notarization на соответствующих ОС.
- В репозитории отсутствуют ключи и сертификаты (секреты берутся из защищённого хранилища CI).
