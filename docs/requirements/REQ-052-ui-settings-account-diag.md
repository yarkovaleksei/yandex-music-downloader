# REQ-052 — [UI] Экраны Settings, Account и Diagnostics

## Requirement

Settings позволяет менять output directory, quality, concurrency, предустановленные шаблоны имён/каталогов, overwrite behavior, FFmpeg и logging; Account показывает состояние авторизации и позволяет выйти; Diagnostics показывает необходимые для использования результаты provider health и doctor-проверок с повторным запуском; desktop-проекция и помощь по FFmpeg уточняются REQ-057, полный CLI doctor сохраняет REQ-034.

## Rationale

Brief §33.

## Acceptance

- Каждая настройка сохраняется и восстанавливается после перезапуска приложения (тест).
- Выход из аккаунта удаляет токен из secure storage.
- Diagnostics отображает необходимые для использования проверки и позволяет их перезапустить; применяет фильтрацию и объяснения REQ-057 без изменения CLI doctor.

- Выбор папки остаётся однострочной кнопкой на desktop; concurrency вводится компактным числовым полем, целое 1–8, без выпадающего списка, некорректное значение не сохраняется.
- «О программе» показывает фактическую текущую версию и пометку dev для разработки без проверки обновлений в сети. Служебное меню Electron File/Edit/View/Window не занимает клиентское окно Linux/Windows.
- Подписка проецируется из подтверждённых данных provider, включая признак Plus и поддержанные формы подписки; отсутствие/неполнота ответа объясняется, неизвестность не выдаётся за отсутствие подписки. Общий перечень форматов не выдумывается: при отсутствии такой account-возможности поясняется проверка вариантов при анализе конкретного трека.
- Аватар текущего аккаунта загружается необязательным запросом; ошибка, отсутствие портрета или отказ прав сохраняют заглушку и не блокируют локальные экраны/аккаунт. Provider получает профиль только текущим токеном; renderer получает ограниченные байты изображения, без токенов, ID портрета и внешнего URL.

- По решению владельца от 2026-10-29 автоматическое открытие папок при завершении заданий отсутствует; настройка удалена, прежний сохранённый флаг игнорируется без миграции/удаления заданий. Ручное открытие остаётся явным действием.
