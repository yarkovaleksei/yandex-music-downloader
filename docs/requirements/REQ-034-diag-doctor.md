# REQ-034 — [DIAGNOSTICS] Команда doctor

## Requirement

`music-downloader doctor` проверяет: Node.js runtime, доступность provider, авторизацию, доступ к аккаунту, запрос метаданных, запрос audio variants, права на файловую систему, наличие FFmpeg (optional) и состояние хранилища; выводит статус каждой проверки, различает несовместимость API и сетевую ошибку и завершается ненулевым кодом при провале обязательной проверки.

## Rationale

Быстрая диагностика нестабильного API.

## Acceptance

- На mock provider каждая из проверок может быть переведена в OK/FAIL, а вывод и exit code соответствуют результату.
- Подмена ответа provider на структурно изменённый даёт в `doctor` отдельный статус «API changed», не равный сетевой ошибке.
- Отсутствие FFmpeg отображается как optional и не приводит к ненулевому коду завершения.
