# REQ-041 — [TOOLING] Локальные проверки перед слиянием

## Requirement

Перед слиянием изменения проверяются локально: lint, typecheck, unit tests, integration tests, build CLI и build core. Сборка CLI/core/desktop и подготовка всех платформенных артефактов выполняются только на Linux. Desktop дополнительно проверяется Electron E2E; на Windows/macOS запускаются готовые собранные на Linux артефакты без компиляции приложения или тестового host. По уточнённому решению владельца от 2026-10-29 CI приложения выполняет только дополнительные Linux-проверки кода и unit tests; успешный CI не является условием приёмки изменений или релиза.

По решению владельца от 2026-10-29 нативные проверки Windows/macOS выполняются на готовых артефактах после разработки и упаковки; промежуточные изменения проверяются на Linux. Перед выпуском обязательна финальная приёмка Windows/macOS. Все сборки выполняются только на Linux; на целевых ОС проверяются готовые артефакты без компиляции.

Отчёты нативной приёмки относятся к конкретным revision/build ID и хешам. Для ранее согласованных переносимых изменений UI без новых платформенных интеграций разрешена отдельная Linux-проверка; прежний платформенный PASS не переносится автоматически на новую сборку.

## Rationale

Регрессии должны ловиться до слияния.

## Acceptance

- Перечисленные локальные команды завершаются успешно; Evidence содержит revision, команды и результаты.
- Обязательные проверки не используют `PROVIDER_TEST_TOKEN` и не выполняют `test:provider`.
- CI приложения выполняет дополнительные проверки только на Linux; Windows/macOS, Electron E2E и сборки дистрибутивов в нём не запускаются. Ожидание или отказ CI не блокирует локальную приёмку.
