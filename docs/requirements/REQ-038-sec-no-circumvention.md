# REQ-038 — [SECURITY] Работа только с доступным аккаунту контентом

## Requirement

Приложение работает только с вариантами аудио, которые provider сообщает доступными текущему авторизованному пользователю. Оно не расшифровывает offline-cache официального клиента, само не извлекает ключи клиента, не выполняет MITM или модификацию официального клиента, не обходит DRM локальных файлов и ограничения аккаунта и не использует чужие credentials. По решению владельца продукта (OQ-012) допустимы публичные OAuth client credentials официального приложения и встроенные в provider-библиотеку константы подписи, а также расшифровка потока ключом, выданным API текущему аккаунту; preview-варианты не выбираются.

## Rationale

Юридические и этические ограничения проекта.

## Acceptance

- В кодовой базе отсутствуют функции чтения offline-cache официального клиента и самостоятельного извлечения ключей из его файлов или памяти (проверяется review); использование констант provider-библиотеки и ключей, выданных API, допускается и документируется в ADR-009 и ADR-010.
- Список вариантов для загрузки формируется исключительно из результата `getAudioVariants` текущего аккаунта.
- Попытка запросить недоступное качество завершается `QualityUnavailableError`, а не обходом.
