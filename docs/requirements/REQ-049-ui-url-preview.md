# REQ-049 — [UI] Вставка URL и предпросмотр до скачивания

## Requirement

После вставки URL приложение определяет тип, получает данные и показывает предпросмотр: тип сущности, название, автора, количество треков, обложку, приблизительный объём (если возможно) и доступные качества; скачивание запускается только действием пользователя.

## Rationale

Пользователь должен понять, что будет скачано (brief §34).

## Acceptance

- Для track, album и playlist на mock application отображаются все перечисленные поля предпросмотра.
- Неподдерживаемая ссылка показывает ошибку под полем ввода без падения приложения.
- Скачивание не стартует без явного нажатия кнопки.
