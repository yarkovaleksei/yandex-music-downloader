# REQ-017 — [QUEUE] Очередь загрузок и concurrency

## Requirement

Загрузка треков проходит через очередь с ограничением параллелизма; значение по умолчанию 4, настраивается в диапазоне 1–8, значения вне диапазона отвергаются ошибкой валидации. Лимит общий для экземпляра приложения (процесса), а не для отдельного job. Playlist не загружается последовательно в обход queue abstraction.

## Rationale

Контролируемый параллелизм снижает риск rate limit и обеспечивает управляемость.

## Acceptance

- Тест с 20 mock-треками и concurrency=3 подтверждает, что одновременно активно не более 3 загрузок и все 20 завершены.
- Значения 0 и 9 отвергаются `ValidationError`; значения 1 и 8 принимаются; значение по умолчанию — 4.
- Через флаг `--concurrency` CLI передаёт значение в очередь.
