# REQ-028 — [PLAYLIST] Каталог playlist и файл .m3u8

## Requirement

Playlist скачивается в отдельный каталог с нумерацией файлов по позиции в источнике и файлом `<Playlist Name>.m3u8` в UTF-8 с относительными путями в порядке плейлиста; недоступные или неуспешно скачанные треки в `.m3u8` не попадают.

Уточнение REQ-058: создание `.m3u8` включено по умолчанию; пользователь desktop может явно отключить его для новых заданий. Каталог, порядок/нумерация аудиофайлов и правила исключения неуспешных треков не меняются; replay сохраняет исходный выбор. Прежние настройки без нового поля продолжают создавать `.m3u8`.

## Rationale

Плейлист должен сохраняться как плейлист, а не россыпь файлов.

## Acceptance

- Интеграционный тест playlist из N треков создаёт каталог, N пронумерованных файлов и `.m3u8`, где строки совпадают с относительными путями файлов в порядке источника.
- Для частично неуспешного playlist `.m3u8` содержит только успешно скачанные треки, а нумерация файлов не сдвигается.
- Названия с кириллицей и пробелами корректно читаются стандартным плеером/парсером `.m3u8`.
