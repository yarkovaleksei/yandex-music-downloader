# REQ-027 — [METADATA] Локальный cache с TTL

## Requirement

Допускается локальный cache метаданных, обложек и ответов provider с TTL; audio cache в MVP не реализуется. Просроченные записи не используются, cache не содержит секретов. Данные, зависящие от аккаунта (доступность, варианты), кэшируются только с ключом по аккаунту либо не кэшируются; информация для скачивания (download info, ссылки на поток) не кэшируется никогда; ключ cache учитывает `PROVIDER_SCHEMA_VERSION`.

## Rationale

Снижение числа запросов к неофициальному API.

## Acceptance

- Повторный запрос метаданных в пределах TTL не обращается к provider (счётчик в тесте); после истечения TTL (инжектируемые часы) запрос повторяется.
- В cache отсутствуют токены, cookies и signed URL (автоматическая проверка).
- Очистка cache не затрагивает manifest и скачанные файлы.
- Записи доступности/вариантов одного аккаунта не используются для другого аккаунта; ссылки на поток не попадают в cache; изменение `PROVIDER_SCHEMA_VERSION` инвалидирует записи.
