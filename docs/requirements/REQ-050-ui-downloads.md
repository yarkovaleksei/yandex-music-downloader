# REQ-050 — [UI] Экран загрузок, прогресс и управление

## Requirement

Экран Downloads показывает активные и ожидающие задания: прогресс задания (N / total, процент), прогресс трека, скорость (если достоверна), ETA (только если стабильна) и действия Pause, Resume, Cancel, Retry, Open folder; завершение и ошибки сопровождаются уведомлениями.

## Rationale

Основной рабочий экран приложения (brief §32, §35, §36).

## Acceptance

- Тест компонента с потоком событий mock application показывает N/total и проценты, а скорость и ETA скрыты при их отсутствии в данных.
- Каждое действие вызывает соответствующий метод `DesktopApi`; недопустимое по state machine действие недоступно (disabled).
- Уведомление показывается при завершении задания и при ошибке.
