# REQ-022 — [FILESYSTEM] Кроссплатформенный filename sanitizer

## Requirement

Единая реализация санитизации имён файлов и каталогов заменяет `< > : " / \ | ? *`, учитывает зарезервированные имена Windows (CON, PRN, AUX, NUL, COM1–COM9, LPT1–LPT9), удаляет trailing пробелы и точки, ограничивает длину пути и имени, сохраняет Unicode и предотвращает path traversal.

## Rationale

Файлы должны создаваться одинаково безопасно на Windows, macOS и Linux (brief §20).

## Acceptance

- Table-driven unit-тесты покрывают запрещённые символы, reserved names (без учёта регистра), trailing пробелы/точки, `..` и абсолютные пути, длинные имена и кириллицу/эмодзи.
- Результат санитизации никогда не выходит за пределы выходного каталога (property/негативные тесты на traversal).
- Одна и та же функция используется для всех платформ; платформенные различия выражены параметром, а не дублированием.
