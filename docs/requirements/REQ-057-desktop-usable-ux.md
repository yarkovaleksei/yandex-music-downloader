# REQ-057 — Компактный desktop UX и понятная диагностика препятствий

## Requirement

Desktop использует доступную ширину окна и закреплённую навигацию с выравниванием пунктов влево. Загрузки представлены свёрнутыми по умолчанию аккордеонами: источник-ссылка, состояние, количество/прогресс и действия доступны в заголовке. Общие действия позволяют приостановить/продолжить допустимые задания, открыть настроенную папку загрузок и убрать завершённые записи из списка без удаления истории или аудиофайлов.

История показывает название-ссылку и доступную обложку. Для плейлиста не перечисляются его треки и совокупность их исполнителей. Действия компактны, доступны с клавиатуры и имеют понятные подписи; отключённый повтор старой записи объясняется tooltip с инструкцией заново открыть источник на Главной и выбрать параметры. Русские количественные подписи имеют правильное склонение.

Desktop-диагностика проверяет только условия, которые могут помешать входу, получению музыки, загрузке и сохранению файлов. Неприменимые проверки без действия пользователя и служебные пункты скрыты. У каждого оставшегося результата понятны смысл, причина проблемы и способ исправления; пропуск из-за блокирующей ошибки объясняет зависимость. Необязательный FFmpeg исключён из общей desktop-диагностики и её итогового статуса, а его проверка, пояснение и ссылка установки для ОС находятся возле настройки FFmpeg. Отсутствие FFmpeg не препятствует базовой работе. CLI doctor сохраняет собственный полный контракт REQ-034.

## Rationale

Решение владельца 2026-10-29 по 12 пунктам и пяти скриншотам, с последующими уточнениями: не показывать неприменимые проверки и проверять только препятствия использованию. Отклонение от иллюстративных макетов явно разрешено. Большие списки и широкие мониторы выявили избыточную прокрутку, нечитабельные строки и необъяснённые технические статусы.

## Acceptance

- При прокрутке большого списка навигация остаётся доступной, подписи выровнены влево, контент использует всю доступную ширину большого окна.
- Аккордеоны изначально свёрнуты; заголовки содержат источник-ссылку, состояние, количество и действия; кнопки не переключают раскрытие.
- Массовые pause/resume затрагивают только допустимые задания, показывают частичные ошибки и не повторяют mutation при неизвестном исходе; общая папка соответствует настройке, индивидуальная — заданию.
- Очистка скрывает только terminal записи в Загрузках, переживает перезапуск, сохраняет историю, jobs/control/leases и аудиофайлы; активные и приостановленные остаются.
- История содержит рабочие публичные ссылки и доступные обложки; плейлист не раздувается перечислением треков/исполнителей; действия компактны, объяснение legacy replay находится в доступном tooltip с дальнейшим действием.
- Подписи корректны для 1/2/5/11/21/22/25/111 треков и других введённых количественных подписей.
- FFmpeg отсутствует в общей desktop-диагностике, остаётся необязательной настройкой с проверкой и Alert info/ссылкой установки по ОС; ничего не скачивается автоматически.
- Неприменимые и служебные строки не показываются; необходимые проверки имеют понятные объяснения и рекомендации без раскрытия секретов; пропуск из-за ошибки не маскируется успехом.
