# REQ-021 — [RESUME] HTTP Range только при реальной поддержке

## Requirement

Возобновление частично скачанного файла с помощью HTTP Range используется только если provider/CDN подтверждённо поддерживает Range (evidence, OQ-003); иначе partial-файл скачивается заново.

## Rationale

Ошибочное продолжение загрузки без поддержки Range даёт испорченный файл.

## Acceptance

- При признаке `acceptsRanges=false` повторная загрузка начинается с нуля и заменяет `.part`.
- При `acceptsRanges=true` загрузка продолжается с корректного смещения и итоговый файл побайтно совпадает с эталоном в интеграционном тесте.
- Решение о Range принимается по возможностям, заявленным provider, а не по предположению core; Range-resume не применяется к `.part`, в который уже записаны теги, или к `.part` с другим `variantKey`/ожидаемым размером.
