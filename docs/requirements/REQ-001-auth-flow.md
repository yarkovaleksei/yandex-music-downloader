# REQ-001 — [AUTH] Авторизация без передачи пароля

## Requirement

Пользователь авторизуется командой `music-downloader auth` через OAuth / Device Authorization (конкретный поддерживаемый flow определяется evidence из STEP-005 и фиксируется в ADR). Приложение никогда не запрашивает, не получает и не сохраняет пароль пользователя Яндекса.

## Rationale

Без авторизации недоступны материалы аккаунта; хранение пароля недопустимо по brief §10.

## Acceptance

- После успешного `auth` команда `account` возвращает идентификатор текущего аккаунта.
- В коде CLI и provider отсутствует поле/prompt ввода пароля Яндекса (проверяется review и тестом, что ни один prompt не запрашивает пароль).
- Выбранный flow подтверждён live-прогоном и задокументирован как evidence (ссылка на OQ-001 resolution).
