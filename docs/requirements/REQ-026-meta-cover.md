# REQ-026 — [METADATA] Встроенная обложка и cover.jpg

## Requirement

В файлы встраивается обложка; для альбомов и плейлистов опционально сохраняется `cover.jpg`. Одинаковая обложка загружается один раз за операцию и переиспользуется из cache для остальных треков. Её байты получает стадия `resolving`, поэтому transient-ошибка использует bounded retry до начала `processing`.

## Rationale

Экономия трафика и согласованный вид библиотеки (brief §22).

## Acceptance

- Загрузка альбома из 12 треков с общей обложкой выполняет ровно один запрос обложки (проверка счётчиком mock provider/HTTP).
- Встроенная обложка читается обратно и совпадает по хэшу с исходным изображением.
- Параметр отключения `cover.jpg` не отключает встроенную обложку и наоборот.
