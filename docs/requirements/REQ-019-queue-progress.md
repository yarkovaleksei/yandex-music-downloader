# REQ-019 — [QUEUE] События прогресса и ограничение достоверности скорости/ETA

## Requirement

Core публикует события прогресса задания (N из total, доля) и трека (доля, полученные байты), а также скорость; скорость и ETA передаются только если достоверно измеримы, иначе отсутствуют.

## Rationale

Недостоверный ETA вводит пользователя в заблуждение (brief §35).

## Acceptance

- Тест подписчика получает монотонно неубывающий прогресс трека от 0 до 1 и счётчик заданий N/total.
- При недостатке данных (менее заданного окна измерения) событие не содержит `speed`/`eta` (тест).
- События содержат `jobId`, `trackKey` (позиция в плане), монотонный `seq` и не содержат signed URL; повторы одного `trackId` в плейлисте различимы по `trackKey`.
