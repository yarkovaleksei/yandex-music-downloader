# REQ-025 — [METADATA] Запись тегов в аудиофайлы

## Requirement

В каждый файл записываются TITLE, ARTIST, ALBUM, ALBUMARTIST, TRACK, DISC, DATE/YEAR и GENRE (при наличии) с корректной Unicode-кодировкой. Для playlist album-метаданные остаются исходными и не подменяются названием плейлиста; принадлежность к playlist выражается каталогом, `.m3u8` и manifest.

Уточнение REQ-058: запись текстовых тегов включена по умолчанию; пользователь desktop может явно отключить её для новых заданий. В выключенном режиме аудиофайл не получает новые текстовые теги; сохранение встроенной и отдельной обложки регулируется независимо по REQ-026. Прежние настройки без нового поля сохраняют запись тегов; replay использует исходные эффективные параметры.

## Rationale

Сохранение исходных музыкальных метаданных.

## Acceptance

- Для каждого поддерживаемого контейнера тест записывает теги и читает их обратно независимой библиотекой/утилитой с совпадением всех полей, включая кириллицу.
- При загрузке playlist тег ALBUM равен названию исходного альбома трека, а не названию плейлиста.
- Отсутствующее необязательное поле не приводит к записи пустой строки-заглушки или ошибке.
