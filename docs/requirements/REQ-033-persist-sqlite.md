# REQ-033 — [PERSISTENCE] SQLite и миграции для desktop

## Requirement

Desktop-версия хранит историю, очередь, задания, настройки и диагностические данные provider в SQLite; SQLite-реализация `ManifestStore` становится единым источником истины для job, manifest и аренды (для CLI и desktop одновременно) с миграциями вида version N → N+1. Несовпадение версии схемы не приводит к пересозданию базы; токены в SQLite не сохраняются.

## Rationale

Надёжное состояние приложения между запусками.

## Acceptance

- Тест миграций применяет все миграции последовательно к базе версии 1 и подтверждает сохранность данных.
- База более новой версии не пересоздаётся и не изменяется; приложение сообщает о несовместимости.
- Автоматическая проверка подтверждает отсутствие токенов в базе.
