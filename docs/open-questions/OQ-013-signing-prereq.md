# OQ-013 — Сертификаты и аккаунты для подписи и notarization релизов

## Context

Подписание Windows/macOS дистрибутивов и notarization требуют сертификатов и аккаунтов владельца (Apple Developer ID, Windows code signing) и связанных расходов; без них REQ pack-update-signing не может быть подтверждён реальной подписью.

## Decision needed

Определить необходимость платных сертификатов Windows/macOS и способ распространения приложения. Ключи собственной подписи обновлений остаются в защищённом хранилище Linux-машины сборки; CI не требуется.

## Resolution

Решение владельца от 2026-10-29: платные сертификаты не покупаются ни сейчас, ни в дальнейшем; нужны portable-версии. Системная code signing и Apple notarization не требуются. Приложение распространяется без установщика: Windows x64 ZIP, macOS arm64/x64 .app ZIP, Linux x64 AppImage. Собственная Ed25519-подпись обновлений не является платным сертификатом и сохраняется. Устойчивое решение — ADR-019; реализация — STEP-036, финальная нативная проверка — STEP-054. Предупреждения ОС о неизвестном издателе допустимы; бесшовный доступ к Keychain и отсутствие системных предупреждений не обещаются.
