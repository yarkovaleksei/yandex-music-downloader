# OQ-012 — Допустимы ли варианты, доступные только в зашифрованном транспорте или как preview?

## Context

Часть вариантов (в том числе lossless) может отдаваться только в транспорте, требующем расшифровки ключом, полученным из API, либо только как preview-фрагменты. PRN-003 запрещает обход DRM и ограничений аккаунта, но ключ, выданный API текущему аккаунту, может считаться штатным поведением provider; brief §5 прямо запрещает лишь обход DRM локальных offline-файлов и ограничений аккаунта. Решение имеет юридические и продуктовые последствия и принадлежит владельцу продукта; STEP-005 обязан собрать evidence о фактическом транспорте и наличии preview.

## Decision needed

После evidence STEP-005 решить: допустимо ли использовать такие варианты как обычные `AudioVariant`, как исключать их из выбора либо ограничить явным пометкой; исключать preview-варианты из выбора по умолчанию.

## Resolution

Решение владельца продукта (2026-10-04): допустимы (1) публичные OAuth client credentials официального приложения Яндекс Музыки, используемые provider-библиотекой для device-авторизации от имени пользователя; (2) константы подписи запросов, встроенные в provider-библиотеку; (3) расшифровка потока (`encraw`) ключом, который API выдаёт текущему авторизованному аккаунту. Недопустимо по-прежнему: самостоятельное извлечение ключей из официального клиента проектом, расшифровка его offline-cache, MITM, модификация клиента, обход DRM локальных файлов и ограничений аккаунта, чужие credentials, preview-варианты как полноценные треки. Preview-варианты исключаются из выбора всегда. STEP-005 по-прежнему собирает evidence о фактическом транспорте вариантов.
