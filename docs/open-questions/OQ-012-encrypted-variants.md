# OQ-012 — Допустимы ли варианты, доступные только в зашифрованном транспорте или как preview?

## Context

Часть вариантов (в том числе lossless) может отдаваться только в транспорте, требующем расшифровки ключом, полученным из API, либо только как preview-фрагменты. REQ-038 запрещает обход DRM локальных offline-файлов и ограничений аккаунта; ключ, выданный API текущему аккаунту, может считаться штатным поведением provider. Решение имеет юридические и продуктовые последствия и принадлежит владельцу продукта; исследование API должно установить сведения о фактическом транспорте и наличии preview.

## Decision needed

После результатов исследования API решить: допустимо ли использовать такие варианты как обычные `AudioVariant`, как исключать их из выбора либо ограничить явным пометкой; исключать preview-варианты из выбора по умолчанию.

## Resolution

Решение владельца продукта (2026-10-04): допустимы (1) публичные OAuth client credentials официального приложения Яндекс Музыки, используемые provider-библиотекой для device-авторизации от имени пользователя; (2) константы подписи запросов, встроенные в provider-библиотеку; (3) расшифровка потока (`encraw`) ключом, который API выдаёт текущему авторизованному аккаунту. Недопустимо по-прежнему: самостоятельное извлечение ключей из официального клиента проектом, расшифровка его offline-cache, MITM, модификация клиента, обход DRM локальных файлов и ограничений аккаунта, чужие credentials, preview-варианты как полноценные треки. Preview-варианты исключаются из выбора всегда. Исследование API по-прежнему фиксирует данные о фактическом транспорте вариантов.
