# PRN-003 — Только доступный аккаунту контент

## Rule

Приложение загружает только то, что provider сообщает доступным текущему авторизованному пользователю; оно не обходит DRM локальных файлов и ограничения аккаунта, не использует чужие credentials, не расшифровывает offline-cache и само не извлекает ключи официального клиента.

## Rationale

Юридические и этические ограничения проекта (brief §5).

## Applies to

Любая функциональность получения аудио, авторизации и работы с файлами официального клиента.

## Exceptions / approved deviation

Исключений нет, кроме явно принятого решения владельца продукта (2026-10-04, OQ-012): допустимы публичные OAuth client credentials официального приложения и встроенные в provider-библиотеку константы подписи запросов, а также расшифровка потока ключом, который API выдаёт текущему авторизованному аккаунту. Проект сам не извлекает ключи из официального клиента.
