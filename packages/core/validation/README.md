# Validation

Базовая проверка выполняется для локального аудиофайла до metadata и после неё,
но до атомарного rename. Она проверяет наличие и ненулевой размер файла,
подтверждённое завершение потока и известный transport size на начальной стадии,
а также контейнер и codec через `music-metadata`. Поддерживаются MP3 и MP4 с
AAC либо FLAC.

Если у трека задана `durationMs`, фактическая длительность должна быть
положительной и отличаться не более чем на `max(1000 мс, 1%)`. Финальная
проверка не сравнивает размер файла с transport size, поскольку metadata может
изменить файл.

`validateWithFfmpeg` — отдельная opt-in проверка полного декодирования. Ей
нужно явно передать путь к системному FFmpeg; пакет не ищет его в `PATH`, не
скачивает и не поставляет вместе с приложением. Отсутствующий executable
возвращает `unavailable` и не делает базовую проверку ошибочной.

Файлы `src/fixtures/` — локальный синтетический corpus; hashes, параметры
генерации и отсутствие provider transport evidence зафиксированы в
`src/fixtures/provenance.json`.
